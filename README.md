# WeatherSphere Pro

A responsive weather web application that fetches live weather information using the Open-Meteo API. Users can search for any city worldwide or use their current location to view real-time weather conditions.

## Features

- Live weather data retrieval
- Search weather by city name
- Current location weather detection
- Temperature display
- Humidity information
- Wind speed tracking
- Feels-like temperature
- Elevation data
- Responsive design
- Modern glassmorphism UI
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## How to Run

### Method 1: Direct Launch

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your browser.

### Method 2: VS Code

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Click "Open with Live Server".

## Usage

1. Enter a city name in the search box.
2. Click Search.
3. View live weather information.

OR

1. Click "Use My Location".
2. Allow location access.
3. View weather for your current location.
